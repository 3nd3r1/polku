# Schedule and deadlines

> The guidebook's schedule graphic doesn't include times for every slot. Times below come from the text sections. Check the Junction Platform and Discord #announcements for the rest.

## Hard deadlines

| When | What | Notes |
|---|---|---|
| **Fri 13.11, 23:59** | Draft submission + pick a challenge | One team member creates the project. The challenge can be changed later. |
| **Sun 15.11, 10:00** | **FINAL submission** | Switch from DRAFT to FINAL. Drafts are not reviewed. No late submissions. |
| **Sun 15.11, 10:30–14:00** | Live peer review | The **whole team must be present**, or you're out of the main prize. |
| Sun 15.11, 18:00 | Venue closes | |

Deadlines for specific challenges (see `challenges/README.md`):
- **Bahn Spread:** ranking from Fri 19:30; final **Sun 08:00** (registration closes 07:30)
- **AstraZeneca:** key insights Fri 20:00 at their stand; judging Sun 14:00
- **Arduino:** also publish on Arduino Project Hub with the tag `Junction Finland 2026`
- **Aalto Humanoid:** Docker submission; finalists run on the real robot Sunday
