## Verda Compute Track

[hackjunction.app/participate/45/tech-challenges/56](https://hackjunction.app/participate/45/tech-challenges/56)

**Task:** pick any Junction challenge and use Verda products to build something you couldn't build on a laptop. One of their example ideas matches us directly: "Keep sensitive data in Europe" by running open-weight models on infrastructure you control instead of sending data to someone else's API.

**Minimum requirements:**
- Document your process
- Post a link to a summary in Verda's Discord channel

**Judging (25% each):**

| Criterion | Question |
|---|---|
| Ambition | How much did compute let you do that you otherwise couldn't? |
| Fit | Did you pick the right Verda services and use them well? |
| Working prototype | Does it run, and is the process documented? |
| Path to scale | Is there a credible way from demo to real users? |

**Products:** Inference API (open-weight models, zero setup), GPU instances and Instant Clusters, CPU instances, auto-scaling containers ("where scale and costs matter"), batch jobs, an NVIDIA Nemotron endpoint.

**Prizes:** 1st $10 000 Verda cloud credits + hoodies · 2nd $2 500 credits · 3rd $2 500 credits.

**Help:** mentors at Booth 6, third floor. Credits: verda.com/blog/junction-2026.

## Best Use of Aiven

[hackjunction.app/participate/45/tech-challenges/43](https://hackjunction.app/participate/45/tech-challenges/43)

**Task:** use at least one Aiven service as a meaningful part of the project, and show what it enables. One service done well counts as much as several. Examples: Aiven Runtime, PostgreSQL, Valkey, Kafka, ClickHouse, OpenSearch.

**Judging:**

| Criterion | Weight |
|---|---|
| Meaningful use of Aiven technology | 40% |
| Technical implementation | 30% |
| Impact on the overall solution | 20% |
| Creativity | 10% |

**Prizes:** 1st 1 000 € · 2nd 750 € · 3rd 500 €.

**Resources:** $50 free credits on signup, Aiven mentors on site all days.
